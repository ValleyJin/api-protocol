# 02. 인터넷 계층 (2층)

## 목표
패킷이 목적지까지 어떤 길로 가는지 따라간다. 주소만으로 전 세계에 깔린 기기 가운데 한 대를 어떻게 집어내는지 확인한다.

## 다루는 것
IP, ICMP, 라우팅

## 만들 것
- IP 헤더를 필드별로 갈라 읽어 주는 파서 (버전, TTL, 프로토콜 번호, 출발지·목적지 주소)
- ICMP Echo 요청을 직접 만들어 보내는 `ping` 흉내 내기
- TTL을 1부터 올려 가며 중간 라우터를 하나씩 드러내는 `traceroute` 흉내 내기

## 확인하는 법
1. `ping`과 `traceroute`를 먼저 그대로 써 보고 출력을 읽는다.
2. 직접 만든 스크립트의 결과를 원래 도구의 출력과 견준다.
3. 같은 목적지에 여러 번 `traceroute`를 돌려 경로가 바뀌는지 본다.

## 메모
`SOCK_RAW`로 ICMP를 직접 만들려면 관리자 권한이 필요하다. macOS는 `SOCK_DGRAM`과 `IPPROTO_ICMP`로 권한 없이 Echo를 주고받는다. 리눅스는 `net.ipv4.ping_group_range` 설정에 따라 갈린다.
