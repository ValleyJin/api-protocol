# WebSocket — 양방향 상시 연결

## 목표
HTTP로 시작해 연결을 유지한 채 양쪽이 아무 때나 말을 거는 방식을 확인한다.

## 만들 것
- HTTP Upgrade 핸드셰이크를 직접 주고받는 최소 클라이언트
- 프레임 헤더(FIN, opcode, mask, payload length)를 조립하고 해석하는 코드
- 같은 일을 `websockets` 같은 라이브러리로 다시 구현

## 확인하는 법
1. 핸드셰이크 요청과 `101 Switching Protocols` 응답을 캡처로 잡는다.
2. 서버가 먼저 보내는 메시지를 클라이언트가 받는지 확인한다.
3. 클라이언트가 보낼 때 마스킹이 걸렸는지 바이트로 확인한다.
