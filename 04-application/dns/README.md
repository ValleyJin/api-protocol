# DNS — 요청-응답 (이름 풀이)

## 목표
이름을 푸는 질의와 응답이 UDP 위에서 어떻게 오가는지 확인한다.

## 만들 것
- DNS 질의 패킷을 바이트로 직접 조립해 보내는 클라이언트
- 응답의 answer 섹션을 파싱해 A 레코드를 뽑는 파서
- 같은 일을 `socket.getaddrinfo`로 다시 구현

## 확인하는 법
1. `dig example.com`을 먼저 돌려 응답 구조를 읽는다.
2. 직접 만든 질의를 `8.8.8.8:53`으로 보내고 응답 바이트를 뜯어 본다.
3. `dig +bufsize=512 +dnssec org DNSKEY @8.8.8.8`로 EDNS0 버퍼를 512로 낮춰, TC 비트가 서고 TCP로 다시 질의하는지 확인한다. EDNS0 버퍼를 그대로 두면 512바이트를 넘겨도 UDP로 온다. 다만 기본 버퍼는 dig 판본마다 다르다. BIND 9.18 이상은 기본이 1232라 이 응답(1319바이트)은 기본값으로도 잘린다. 그때는 `+bufsize=4096`과 견준다.
