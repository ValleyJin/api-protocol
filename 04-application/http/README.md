# HTTP — 요청-응답

## 목표
HTTP/1.1이 TCP 위에 얹힌 텍스트 규약이라는 것을 직접 확인한다.

## 만들 것
- 소켓으로 HTTP 요청 문자열을 직접 써서 보내는 최소 클라이언트
- 요청 줄과 헤더를 파싱해 응답하는 최소 서버
- 같은 일을 `http.client`(표준 라이브러리)나 `requests`(외부 패키지)로 다시 구현

## 확인하는 법
1. `socket`으로 `GET / HTTP/1.1\r\nHost: example.com\r\n\r\n`을 그대로 보내고 응답 원문을 읽는다.
2. Keep-Alive를 켜고 끄며 연결이 유지되는지 캡처로 본다.
3. 라이브러리 버전과 원문 버전의 코드 줄 수를 견준다.
