# 01. 네트워크 인터페이스 계층 (1층)

## 목표
프레임이 실제로 어떻게 생겼는지 눈으로 확인한다. 같은 랜 안에서 기기끼리 서로를 어떻게 찾아내는지 따라간다.

## 다루는 것
이더넷 프레임, MAC 주소, ARP, Wi-Fi

## 만들 것
- 인터페이스 목록을 뽑고 각 인터페이스의 MAC 주소를 확인하는 스크립트
- 캡처한 프레임의 헤더를 바이트 단위로 갈라 읽어 주는 파서
- ARP 요청과 응답 한 쌍을 잡아내는 캡처 스크립트

## 확인하는 법
1. `ip link` 또는 `ifconfig`로 인터페이스와 MAC 주소를 본다.
2. `arp -a`로 ARP 캐시를 확인하고 비운다. macOS는 `sudo arp -d -a`, 리눅스는 `sudo ip neigh flush all`을 쓴다. 그다음 같은 랜의 기기에 `ping`을 보낸다.
3. `sudo tcpdump -i <iface> -e arp`로 오가는 요청과 응답을 잡는다. 캡처에는 관리자 권한이 필요하다.
4. 잡은 프레임에서 목적지 MAC, 출발지 MAC, 이더타입이 어디에 있는지 짚어 본다.

## 메모
ARP는 IP 주소를 다루지만 인터넷 계층에 속하지 않고 이 계층에 속한다. IP 위에서 라우팅되지 않고 같은 링크 안에서만 돌기 때문이다.
